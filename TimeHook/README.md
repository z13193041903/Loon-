# 改时间小模块（学习用）

作者：KEMO

## 它是干什么的

一个在 LSPosed 里跑的小模块，**只改今日水印相机的时间**，手机其他 App 不受影响。

用法：在模块的设置页里选一个日期和时间，点保存。从保存那一刻起，
今日水印相机眼里的时间就从你选的那个点开始，一秒一秒按真实速度往前走。
关掉设置页里的开关，就恢复成真实时间。

## 文件都是干什么的

- `MainActivity.java` — 设置页：选时间、开关、保存
- `ConfigProvider.java` — 配置小通道：把设置递给今日水印相机那边读
  （两边是两个程序，各自的小本子看不见对方，所以要开个小窗口递话）
- `TimeHook.java` — 挂钩代码：跑进今日水印相机里面，
  盯住它问“现在几点”的那一句，把答案换成假时间

## 怎么打包成安装包（在电脑上）

1. 打开 Android Studio，选「打开项目」，选这个文件夹（time-hook-module）
2. 第一次打开会慢慢下载需要的零件，等它跑完（右下角进度条走完）
   - 如果它提示 Gradle 有问题，先别乱点，把截图发给 Muse 看
3. 点顶部菜单 Build → Build App Bundle(s) / APK(s) → Build APK(s)
4. 打好的安装包在 `app/build/outputs/apk/debug/app-debug.apk`

## 怎么装到手机上用

1. 把 app-debug.apk 传到那台安卓手机上，点开安装
2. 打开 LSPosed → 模块 → 找到「改时间小模块」→ 打开它的开关
3. 作用范围（作用域）里**只勾「今日水印相机」**，别的不要勾
4. 把今日水印相机彻底关掉（从后台划掉），再重新打开
5. 打开「改时间小模块」→ 打开开关 → 选日期和时间 → 点保存
6. 再把今日水印相机彻底关掉重开，拍一张照片，看水印上的时间对不对

## 先说清的两个边界

- 它改的是今日水印相机在手机本地问到的时间。如果某个地方的时间是
  它跟服务器对出来的（服务器时间），这个办法改不到。
- 设置改完之后，它最多过 30 秒会自己刷新；想马上生效，
  就把今日水印相机彻底关掉再打开。
