# 悬浮按钮练手（作者：KEMO）

一个专门用来学习的小模块，本身不干任何坏事：
它只在手机的**系统设置**界面上，放一个半透明的小按钮。

## 玩法

1. 把打好的 apk 装到安卓手机上；
2. 打开 LSPosed → 模块 → 启用「悬浮按钮练手」，作用域勾「设置」；
3. 打开系统设置，界面上就会多出一个小按钮：
   - **拖**：按住拖到任意位置，它会记住位置；
   - **点**：轻点一下，弹出设置面板，能改文字、透明度，还能让按钮变成一个小秒表；
   - 在桌面打开模块自己的设置页，也能改同样的设置——两边立刻同步。

## 这一课学到的东西（都是 Xcamera 用过的真技术）

| 技术 | 在这个模块里 | 在 Xcamera 里 |
| --- | --- | --- |
| 往别人界面上贴按钮 | 盯住页面打开的时刻，把按钮塞进最上层画布 | 一模一样，贴在拍照界面上 |
| 拖动按钮 | 记下按下位置，手指移动多少按钮跟多少 | 同上 |
| 点开设置面板 | 面板是当场用代码拼出来的 | 它的设置页也是代码拼的（还多了个验卡密，所以慢） |
| 两边共用一份设置 | 配置小通道（ConfigProvider），能读能写 | 它没这一层，所以改了设置要重开模块才生效 |

## 文件说明

- `MainActivity.java`：模块自己的设置页（桌面点开时看到的）。
- `ConfigProvider.java`：配置小通道——设置真正的主人，两边都找它。
- `FloatHook.java`：悬浮按钮本体（贴按钮、拖动、面板、每秒刷新）。
- `AndroidManifest.xml`：模块的“户口本”。
- `assets/xposed_init`：告诉 LSPosed 入口类是哪一个。

## 打包

用 Android Studio 打开这个文件夹，点 Build APK 即可；
也可以让 Muse 用现成的手工打包流程直接出 apk。
